# 🧮 Простой консольный калькулятор на Python

Минималистичный проект калькулятора, работающий в терминале. Создан для демонстрации базовых навыков работы с языком Python и системой контроля версий Git.

## ✨ Функции
* Сложение, вычитание, умножение и деление.
* Обработка ошибок (защита от деления на ноль и ввода текста вместо чисел).
* Интерактивный цикл работы в консоли.

## 🚀 Как запустить проект
1. Убедитесь, что у вас установлен Python (версии 3.x и выше).
2. Скачайте файл `main.py`.
3. Откройте терминал/консоль в папке с файлом.
4. Запустите программу командой:
   ```bash
   python main.py
   ```
